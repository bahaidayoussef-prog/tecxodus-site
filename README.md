# Tecxodus website

Static showcase site for Tecxodus logistics and warehousing services in Aïn Sebaâ, Casablanca.

## Contents

- index.html: homepage and service showcase
- responsive.css: shared mobile and tablet layout improvements
- blog/: 120 articles with contextual links and metadata
- sitemap.xml, robots.txt: search crawler files
- llms.txt, llms-full.txt: AI crawler and language-model discovery files
- wordpress/tecxodus-wordpress-import-120-articles.xml: WordPress WXR import with 120 posts set to draft
- editorial/: source drafts and SEO/GEO internal-linking plan

## Publishing

The HTML site can be hosted as a static site. The WordPress WXR file imports the articles as drafts; review them in WordPress before publishing. If the site's WordPress URLs or host change, regenerate canonical links, the sitemap, and crawler files for the final production domain before submitting them.

The sitemap lists the public article URLs intended for https://tecxodus.com/. Submit it only after those URLs are live.

## Content and imagery notes

The 20 new technical/contract articles include illustrative stock images loaded from Pexels. They do not depict Tecxodus's actual warehouse. All MAD prices and most productivity figures in the worked examples are explicitly fictional teaching assumptions, not Tecxodus offers or verified Morocco market rates. Replace them with validated local data before using them as a commercial quotation.
